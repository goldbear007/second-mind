# Строймозг — второй мозг для строительных проектов

Личная база знаний по стройпроектам в духе Obsidian. Работает в браузере на ПК и телефоне. Данные хранятся в папке на вашем Google Диске.

**Что умеет**

- Карточки разных типов: объект, контракт, смета/ССР, решение, норматив, организация, контакт, документ, задача, заметка. У каждого типа свои поля («штамп»).
- Связи: `[[Название]]` в тексте и полях, а также связи с типом («основание», «заменяет», «контакт по» и др.). Есть обратные ссылки.
- Граф: общий и вокруг выбранной карточки.
- Хронология объекта: письма, решения, версии смет и задачи по датам.
- ССР из Excel (xlsx/xls): разбор по главам, итог, НДС. Сравнение двух версий по главам и строкам.
- База контактов: телефоны и почта нажимаются, есть фильтр по проекту.
- Переименование карточки обновляет ссылки на неё во всех карточках.
- Экспорт и импорт всей базы в JSON.

## Структура

```
index.html            — страница приложения
css/app.css           — оформление
js/config.js          — НАСТРОЙКИ (сюда вставляется Google Client ID)
js/drive.js           — работа с Google Диском
js/estimate.js        — чтение ССР из Excel и сравнение версий
js/app.js             — само приложение
manifest.webmanifest  — установка на телефон «как приложение»
icon.svg              — значок
.nojekyll             — служебный файл для GitHub Pages
```

Сборка не нужна: это обычные статические файлы.

## Шаг 1. Публикация на GitHub Pages

1. Зарегистрируйтесь или войдите на https://github.com.
2. Нажмите **New repository**. Имя, например, `stroymozg`. Тип — **Public**: бесплатные GitHub Pages работают только с публичными репозиториями. В самом репозитории только код, ваших данных там нет.
3. В новом репозитории нажмите **uploading an existing file**. Перетащите туда все файлы и папки из архива вместе с `.nojekyll`, затем нажмите **Commit changes**.
   - Если не видно `.nojekyll` (скрытый файл), создайте его вручную: **Add file → Create new file**, имя `.nojekyll`, содержимое оставьте пустым.
4. Откройте **Settings → Pages**. В блоке *Build and deployment* выберите *Source: Deploy from a branch*, *Branch: main*, папку `/ (root)` и нажмите **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/stroymozg/`.

Приложение уже работает: данные хранятся в браузере. Чтобы данные были общими для ПК и телефона, выполните шаг 2.

## Шаг 2. Подключение Google Диска

Нужно один раз получить у Google «Client ID». Это публичный идентификатор приложения, а не пароль: его можно хранить в открытом репозитории.

1. Откройте https://console.cloud.google.com/ и создайте проект (вверху: выбор проекта → **New project**, имя `Stroymozg`).
2. **APIs & Services → Library**: найдите **Google Drive API** и нажмите **Enable**.
3. **Google Auth Platform** (или **OAuth consent screen**):
   - App name: `Строймозг`, support email — ваш адрес;
   - Audience / User type: **External**;
   - в списке **Test users** добавьте свой Google-аккаунт. Пока приложение в режиме тестирования, войти смогут только перечисленные там адреса.
4. **Clients** (или **Credentials → Create credentials → OAuth client ID**):
   - Application type: **Web application**;
   - **Authorized JavaScript origins**: `https://ВАШ_ЛОГИН.github.io` (без `/stroymozg` и без слэша в конце); для запуска на своём компьютере добавьте ещё `http://localhost:8000`;
   - Redirect URIs заполнять не нужно.
5. Скопируйте **Client ID** (вида `123…-abc….apps.googleusercontent.com`).
6. На GitHub откройте `js/config.js` и нажмите на карандаш (Edit). Вставьте ID вместо `ВСТАВЬТЕ_CLIENT_ID.apps.googleusercontent.com` и нажмите **Commit changes**.
7. Обновите сайт и нажмите внизу слева **«Подключить Google Диск»**. Google спросит разрешение на доступ к файлам, созданным этим приложением: разрешите.

Как устроена папка на Диске:

```
Мой диск/
  Строймозг/
    Карточки/   — по одному файлу .md на карточку (можно открыть и прочитать)
    Файлы/      — исходные Excel-файлы загруженных ССР
```

Что важно знать:

- Приложение получает доступ **только к файлам, которые создало само**. Остальной Диск оно не видит. Поэтому файлы, положенные в папку вручную, в приложении не появятся.
- Вход в Google действует около часа. Когда сессия истечёт, правки копятся в браузере. Нажмите «Подключить Google Диск», и они уйдут на Диск.
- Карточки, созданные до подключения Диска, выгрузятся туда автоматически при первом подключении.
- Изменения с другого устройства подтягиваются при возврате во вкладку, раз в минуту и по кнопке «Обновить».

## Установка на телефон

Откройте сайт в Chrome (Android) или Safari (iPhone) и выберите **«Добавить на главный экран»**. Приложение откроется без адресной строки, как обычное.

## Запуск на своём компьютере (для правок)

```
cd папка_с_файлами
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Импорт ССР

В карточке типа «Смета / ССР» нажмите **«Загрузить из Excel»**. Разбор ищет:

- строки `Глава N …` — начало главы;
- `Итого по главе N` — итог главы (если такой строки нет, итог считается по строкам);
- `Итого по главам …` — промежуточные итоги;
- `НДС …` и `Всего по сводному сметному расчёту` — налог и итог;
- колонку «Общая сметная стоимость»; если её нет, берётся крайнее правое число в строке.

Чтобы сравнить версии, откройте новую версию ССР и выберите в списке «Сравнить с» старую. Если у новой есть связь «заменяет → старая», старая подставится сама.
